# Scratch Dodge

Dodge obstacles, avoid lasers, collect coins, and survive as long as you can in this fast-paced arcade dodging game.  
Unlock different skins, master tight movement, and push your survival time higher and higher.  
Originally built in **Scratch**, then ported to run on Windows.

---

## 🚀 Features

- ⚡ Fast-paced dodge gameplay  
- 🚧 Spikes, lasers, and moving hazards  
- 🪙 Coin collection system  
- 🎨 Unlockable skins  
- 🏆 Endless survival mode  
- 🎮 Simple controls, challenging gameplay  
- 🖥️ Windows EXE version included  
- 🧩 Scratch `.sb3` source file included
